# go-puppet docs

MkDocs Material documentation for **[go-puppet](https://github.com/go-puppet)** —
a pure-Go implementation of the Puppet language. Versioned with
[mike](https://github.com/jimporter/mike) and served at
<https://go-puppet.github.io/docs/>.

```sh
pip install -r requirements.txt
mkdocs serve   # local preview at http://127.0.0.1:8000
```

The `docs` workflow deploys versioned docs to the `gh-pages` branch on every
push to `main`. BSD-3-Clause.
